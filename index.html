01 / HOW TO PLAY

วิธีเล่นพื้นฐานฉบับชุดการ์ดปกติ

Phase เบื้องต้น
เริ่มเทิร์น - Pocket Phase - Main Phase - End Phase
Pocket Phase = ในช่วงนี้จะมีการกระทำ 2 อย่างคือ
1 ) ทำการเปลี่ยนสภาพการ์ดบนสนามเป็นสภาพ OK จากสภาพ Don't และ จั่วการ์ด 1 ใบ
2 ) ทำการหา Pocket รวมกัน 1-2 ใบจาก เด็ค, Tomp, Energy, การ์ดบนมือ หากนำจากบนมือให้ทำการจั่วการ์ด 1 ใบ, หากนำจากในเด็คให้สลับกองการ์ด, หากนำจาก Energy, ให้ทำการนำการ์ดใบบนสุดไปวางคว่ำหน้าที่เป็น Energy แทน
โดยทั้ง 2 อย่างนี้จะต้องทำ ให้ครบ และสามารถเรียงลำดับได้ว่าจะทำขั้นตอนไหนก่อน
Main Phase = สามารถลง Character, ใช้งาน Action, ติดตั้ง Gear, เปิดใช้งาน Zone, ใช้ความสามารถ
สั่งโจมตี, ขโมย Soul Core, ใช้งาน Ultimant, สั่งใช้งานความสามารถ Activat
End Phase = ใช้ความสามารถเมื่อจบเทิร์นและเปลี่ยนให้ฝั่งตรงข้ามเล่นต่อ


วิธีการเล่นพื้นฐาน
1 ) เริ่มเกม นำการ์ด Soul Core ไปวางที่โซน SC และนำการ์ด Master กับ Zone ไปวางที่โซน M และ Z ในสภาพคว่ำหน้า และเมื่อประกาศ UNSEAL!!! เพื่อเริ่มการต่อสู้ ทำการจั่วการ์ดขึ้นมือ 5 ใบ หากบนมือมีการ์ด Pocket 4 หรือ 5 ใบ ให้แสดงการ์ดบนมือทั้งหมดให้คู่แข่งเห็นและนำการ์ดบนมือทั้งหมดสลับกลับกองการ์ด จากนั้นจั่วใหม่ 5 ใบ (หากมี Pocket 3 ใบหรือน้อยกว่าจะไม่สามารถเปลี่ยนได้)
2 ) Pocket Phase จะต้องทำทั้ง 2 ตัวเลือก
2.1 ) ทำการเปลี่ยนสภาพการ์ดบนสนามเป็นสภาพ Ok จากสภาพ Don't และ จั่วการ์ด 1 ใบ
2.2 ) หาการ์ด Pocket จากที่ไหนก็ได้ ไม่ว่าจะเป็น กองการ์ด, Tomp, บนมือ, Energy รวมกัน 1-2 ใบแล้วเอามาวางที่ Pocket Area ถ้าเอาจากมือให้จั่วการ์ดตามจำนวน และ ถ้าเอาจาก Energy ให้นำใบบนสุดจากกองไปคว่ำหน้าไว้ตรง Energy Area ตามจำนวน และหลังจากนั้น หากคุณนำการ์ดPocketมาวางที่Pocket Area 1 ใบ ให้จั่วการ์ดเพิ่ม 1 ใบ (ยกเว้นบนPocket Area ของคุณมีPocket ครบ 10 ใบ แล้วเงื่อนไขนี้จะไม่ทำงาน)
ขั้นตอนนี้จะจั่วก่อนหรือจะหา Pocket ก่อนก็ได้
3 ) Main Phase ช่วงนี้จะทำได้ทุกอย่างเลย ลงการ์ดจากมือ ใช้ความสามารถของการ์ด ประกาศโจมตีหรือขโมย ทำการ Unite Zone วิธีการลงการ์ด character จะต้องเปลี่ยนสภาพของการ์ด Pocket ให้เป็นสภาพ Don't ตามจำนวนค่าคอสมุมซ้ายบน Action และ Gear ก็วิธีเดียวกัน วิธีการโจมตีและขโมย ให้เปลี่ยนสภาพของการ์ดที่จะโจมตีหรือขโมย เป็น Don't เพื่อทำการโจมตีใครที่มีพลังมากกว่าจะเป็นคนชนะ หากมีพลังเท่ากัน คนที่โจมตีจะเป็นฝ่ายชนะ
4 ) ช่วง End Phase จะสามารถใช้งานความสามารถที่บอกว่าเมื่อจบเทิร์นได้จากนั้นให้คู่แข่งเล่นต่อ


เงื่อนไขการจบเกม มีทั้งหมด 4 แบบ
1 ) Soul Core ฝ่ายใดหมดก่อนและโจมตี Master อีก 1 รอบจะถือว่าชนะ
2 ) มีฝ่ายใดขโมย Soul Core ได้ 7 ใบก่อนและโจมตี Master อีก 1 รอบจะถือว่าชนะ
3 ) เมื่อไม่สามารถจั่วการ์ดได้จะถือว่าแพ้
4 ) สามารถชนะด้วยเงื่อนไขพิเศษของการ์ดได้


กฏเกมพื้นฐาน
1 ) คนเริ่มคนแรกจะไม่มีตัวเลือกการจั่วการ์ดในช่วง Pocket Phase (ถ้านำ Pocket จากมือไปวางจะยังได้จั่วเหมือนเดิม)
2 ) การ์ด Action จะใช้ได้ก็ต่อเมื่ออยู่ใน Main phase เทิร์นตัวเอง ยกเว้นใบนั้นจะมี counter ถึงจะใช้ในเทิร์นอีกฝ่ายได้
3 ) ความสามารถของการ์ดถ้าไม่ได้บอกว่าใช้ในเทิร์นอีกฝ่ายได้หรือมี counter จะไม่สามารถใช้ในเทิร์นคู่แข่งได้ ต้องใช้งานใน Main Phase เท่านั้น
4 ) ความสามารถ Forever จะทำงานตลอดต่อเมื่อเงื่อนไขครบ
5 ) เมื่อใช้ Ultimant แล้ว จะไม่สามารถใช้การ์ดอื่นได้อีกยกเว้นจะมีความสามารถของ Ultimant เพิ่มเติม
6 ) จะเปิดการ์ด Zone ได้ต่อเมื่ออยู่ในช่วง Main Phase เทิร์นตัวเองเท่านั้น
7 ) เมื่อ character ลงบนสนาม จะสามารถโจมตีหรือขโมยได้ทันทียกเว้นจะมีความสามารถทำให้โจมตีไม่ได้
8 ) การ์ด Gear จะสามารถสวมใส่ให้ได้เฉพาะการ์ดตามเงื่อนไขเท่านั้น
9 ) การ์ด Master จะสามารถจะสามารถ Unite Zone ได้เฉพาะชื่อ Zone บนการ์ดMaster เท่านั้น หากชื่อไม่ตรงกับที่ระบุไว้ จะไม่สามารถเปิดใช้งานได้
10 ) Character ถ้าช่องเต็ม 4 ช่องไม่สามารถลงเพิ่มหรือทับได้นอกจากจะมีความสามารถที่ทำให้เกิดขึ้นได้
11 ) การ์ดใน Underworld ถือเป็นการ์ดที่อยู่ด้านนอกเกม ไม่สามารถนำออกมาได้ นอกจากจะมีความสามารถเจาะจง
12 ) character, Master 1 ใบ สามารถ สวมใส่ Gear ได้ 1 ใบเท่านั้น ยกเว้นจะมีความสามารถเพิ่มเติม
13 ) การจ่ายหรือขโมยการ์ด Energy Soul จะต้องเปิดการ์ดใบแรกสุดจากด้านบนเสมอ
14 ) ฝ่ายโจมตีถ้าพลังเท่ากับหรือน้อยกว่าฝ่ายรับ ฝ่ายตีจะไม่โดน Kill จากการต่อสู้
15 ) ถ้ามีการทอยลูกเต๋า ต้องทอยลูกเต๋าที่มีจำนวนหน้าตามที่การ์ดบอกเท่านั้น เช่น D6 D12 D20
16 ) ถ้ามีการทอยเหรียญ จะต้องเป็นเหรียญที่มีหัวก้อยเท่านั้น
17 ) คนที่ชนะการทอยลูกเต๋าหรือชนะอะไรก็ตามๆที่ตกลง จะมีสิทธิ์เลือกเล่นก่อนหลังได้
18 ) หากเมื่อโจมตีแล้วพลังเท่ากันฝ่ายโจมตีหรือขโมยจะเป็นฝ่ายชนะเสมอ
19 ) เมื่อทำการ Unite Zone จะไม่ถือว่าเป็นการกระทำไม่สามารถใช้งาน Counter ได้ต่อเมื่อใน
20 ) Soul Core จะต้องเรียงลำดับตามเลขของการ์ดเท่านั้น
21 ) การ์ด Energy Soul จะสามารถเปิดดูได้ตลอดเวลาโดยไม่ให้คู่แข่งเห็น แต่จะต้องอยู่ในตำแหน่งเดิมห้ามเปลี่ยนแปลง
22 ) การ์ดที่มีความสามารถ counter จะสามารถใช้ได้เมื่อมีการกระทำเกิดขึ้นเท่านั้น
23 ) การเปลี่ยน Phase จะไม่นับว่าเป็นการกระทำและไม่สามารถใช้งานการ์ดที่มีความสามารถ counter ได้
24 ) การ์ดในชุด HD ไม่สามารถใช้งานร่วมกับการ์ดในชุดปกติได้
25 ) Unite คือการหลอมรวมเข้ากับ Zone เพื่อสั่งใช้งานความสามารถของ Zone นั้น 26 ) ยังไม่เปิดเผย
26 ) ยังไม่เปิดเผย
27 ) ยังไม่เปิดเผย

หมายเหตุวิธีเริ่มเกม ลำดับการเล่นในเทิร์น วิธีโจมตี และเงื่อนไขการจบเกม และกฏ อาจจะมีเพิ่มเติมในภายหลัง โดยวิธีเล่นนี้จะใช้กับชุดการ์ดปกติ เฉพาะผู้เล่น 2 คน และไม่ใช่ชุด HD เท่านั้น

03 / CARD TYPES

รู้จักประเภทการ์ด

M
Master

การ์ด Master ประจำเด็ค แยกจากตัวเด็ค เป็นการ์ดผู้นำที่รับผิดชอบเก็บและปกป้อง Soul Core มีความสามารถ 2 ฝั่ง ฝั่งซ้ายเป็นความสามารถที่เป็นความสามารถที่ใช้ได้ตั้งแต่เริ่มเกม ความสามารถฝั่งขวาคือความสามารถที่ต้องรอให้ Zone ทำการ Unite ก่อนถึงจะสามารถใช้งานได้

Z
Zone

แยกจากตัวเด็ค เป็นการ์ดพื้นที่ที่มีด้านหน้าและด้านหลัง โดยด้านหลังจะเป็นเงื่อนไขในการ Unite Zone ส่วนด้านหน้าจะเป็นความสามารถของ Zone

SC
Soul Core

เป็นการ์ดที่แยกออกจากตัวเด็คจำนวน 7 ใบ เมื่อถูกขโมยหรือทำลายจนครบ 7 ใบก็แพ้ หรือถ้าขโมยจนครบ 7 ใบก็ชนะ

Pocket
Pocket

เป็นการ์ดที่รวมอยู่ในเด็ค ทำหน้าที่เป็นค่าคอสเหมือนเป็นสิ่งที่เรียกใช้วิญญาณได้ ด้วยจำนวนที่กำหนด และ ยังสามารถใช้งานความสามารถ Counter ของ Pocket ได้ด้วย ต้องมีจำนวน 10 ใบในเด็ค

C
Character

เป็นการ์ดที่รวมอยู่ในเด็ค เป็นการ์ดตัวละคร เหมือนเป็นพวกพองที่ฝากจิตวิญญาณไว้กับ Master โดยมี ค่าคอส ในการลงสนาม และความสามารถจากการ์ดจริง

-
Action

การ์ด Action ที่มีเงื่อนไขและผลแตกต่างกันตามข้อความบนการ์ด

-
Gear

การ์ดอุปกรณ์ โปรดตรวจสอบข้อกำหนดการสวมใส่ที่ระบุไว้บนการ์ด

-
Untimeat

เป็นการ์ดที่รวมอยู่ในเด็ค การ์ดใบนี้จะมีอยู่ในเด็คได้เพียง 1 ใบ เท่านั้น เป็นการ์ดท่าไม้ตาย เมื่อใช้งานแล้วจะลง Tomp นอกจากจะมีความสามารถพิเศษ หลังจากใช้งานแล้วจะไม่สามารถใช้งานการ์ดอื่นได้ และไม่สามารถโจมตีหรือขโมยได้

Energy
Energy

เป็นช่องที่เอาไว้จ่าย Energy Soul และ การ์ดในช่องนี้จะเป็นสภาพคว่ำ สามารถดูได้ตลอดเวลาโดยห้ามเปลี่ยนตำแหน่ง

ยังไม่เปิดเผย

Counter ความสามารถหลังสัญลักษณ์นี้จะใช้งานตอนใดก็ได้ที่มีการกระทำเกิดขึ้น
Peek เปิดดูการ์ดตามจำนวนที่อยู่หลังสัญลักษณ์นี้ ถ้าไม่มีบอกว่าเปิดที่ไหนจะเปิดดูใบบนสุดจากกองเจ้าของเสมอ (ดูคนเดียว)
1/Turn ความสามารถที่มีสัญลักษณ์นี้ จะใช้ได้เพียงแค่ เทิร์นละ 1 ครั้ง
Unite Zone เป็นเงื่อนไขการสั่ง Unite Zone เพื่อให้การ์ด Zone ทำงาน
Pocket ใช้ระบุว่าต้องทำการจ่าย หรือได้รับ Pocket ตามที่ระบุในความสามารถการ์ด
Energy Soul เป็นการนำการ์ดใบบนสุดจากกองการ์ดไปคว่ำหน้าที่Energy Area ตามจำนวนที่ระบุ (สามารถดูได้คนเดียว)
Forever ความสามารถหลังการ์ดนี้จะทำงานตลอดเวลาเมื่อเงื่อนไขครบถ้วน
Activat เป็นความสามารถที่ต้องทำการสั่งใช้งานถึงจะแสดงผล
Block การ์ดที่มีความสามารถนี้ สามารถเปลี่ยนจากสภาพ Ok เป็น สภาพ Don't ได้ หากทำจะเปลี่ยนการโจมตีหรือขโมยมาที่การ์ดใบนี้แทน
Enter เมื่อการ์ดใบนี้เข้าสู่สนามความสามารถหลังสัญลักษณ์นี้จะแสดงผล
Energy เป็นสัญลักษณ์ที่ เอาไว้จ่าย Energy ตามจำนวนที่ระบุ จาก Energy Area (ต้องทำการจ่ายนับจากใบบนสุดเท่านั้น)
Unite Zone - ... ความสามารถหลังสัญลักษณ์นี้จะทำงานเมื่อการ์ด Zone เคย Unite ไปแล้วในเกมนี้เท่านั้น
